# عبر المحيط لاستيراد السيارات

موقع الشركة وبوابة العملاء ولوحة الإدارة. الموقع مستضاف على Vercel، والبيانات محفوظة في مخزن Vercel Blob خاص.

## الأقسام
- **الشركة** (`#home`): تعريف بالخدمات ومراحل الطلب وبيانات التواصل.
- **حسابي** (`#portal`): العميل يدخل بكوده ويشوف فواتيره ومدفوعاته والمتبقي عليه.
- **الإدارة** (`#admin`): دخول بكلمة مرور. منها تضيف العملاء والفواتير والدفعات وبيانات الشركة.

## كيف يشتغل
- `index.html`: الواجهة كاملة.
- `api/`: دوال Vercel اللي تقرأ وتكتب البيانات.
  - `settings`: بيانات الشركة (عامة).
  - `statement`: كشف حساب عميل واحد بالكود.
  - `login`: دخول الإدارة بكلمة المرور.
  - `admin`: إضافة وتعديل وحذف (يحتاج دخول).
- البيانات كلها في ملف خاص `abr/db.json` داخل مخزن Blob، وما يقدرش حد يوصله إلا من خلال الـ API.

## الإعدادات (Vercel → Project → Settings → Environment Variables)
- `ADMIN_PASSWORD`: كلمة مرور الإدارة. غيّرها من هنا وبعدها دير Redeploy.
- `ADMIN_SECRET`: مفتاح توقيع جلسات الإدارة. تغييره يخرّج كل الأجهزة المسجلة.
- `BLOB_READ_WRITE_TOKEN`: ينضاف تلقائياً لما يتربط مخزن Blob بالمشروع.

## ملاحظات
- أي تعديل يترفع على فرع `main` في GitHub، Vercel ينشره تلقائياً.
- لو فتحت الموقع على جهازك بدون الـ API، يشتغل في وضع تجريبي والبيانات تنحفظ في المتصفح بس.
