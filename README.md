# عبر المحيط لاستيراد السيارات

موقع الشركة وبوابة العملاء ولوحة الإدارة. الموقع مستضاف على GitHub Pages، والبيانات محفوظة في Supabase.

## الأقسام
- **الشركة** (`#home`): تعريف بالخدمات ومراحل الطلب وبيانات التواصل.
- **حسابي** (`#portal`): العميل يدخل بكوده ويشوف فواتيره ومدفوعاته والمتبقي عليه.
- **الإدارة** (`#admin`): دخول بالإيميل وكلمة المرور. منها تضيف العملاء والفواتير والدفعات وبيانات الشركة.

## ربط قاعدة البيانات (مرة واحدة)
1. افتح حساب في https://supabase.com وأنشئ مشروع جديد.
2. من **SQL Editor** افتح `setup.sql`، وغيّر `admin@example.com` في آخر سطر لإيميل الإدارة، وبعدها اضغط **Run**.
3. من **Authentication → Users → Add user** سجّل نفس الإيميل بكلمة مرور.
4. من **Authentication → Sign In / Providers** طفّي خيار **Allow new users to sign up**.
5. من **Project Settings → API** انسخ `Project URL` و`anon public key` وحطهم في `config.js`.

قبل الربط، الموقع يشتغل كنسخة تجريبية والبيانات تنحفظ في المتصفح بس.

## الحماية
- العميل ما يقدرش يشوف إلا كشف حسابه، ومن خلال دالة `client_statement` وبالكود بس.
- الجداول نفسها ما يقرأها ولا يعدلها إلا الإيميلات المسجلة في جدول `admins`.
- الكود الجديد يتولد عشوائي (`OC-` + 8 خانات)، فصعب حد يخمنه.
